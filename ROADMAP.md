# Дорожная карта BotPlus PDF Editor

Состояние: **1.6**, обновлено **14 октября 2026 года**. В карте остаются только незавершённые задачи. История выполненных задач — в Git и RELEASE_NOTES.md. Номера задач постоянные: после удаления остаются пропуски, новые задачи получают новые номера.

Порядок ниже — инженерная оценка от самых простых до самых сложных задач для текущей архитектуры SwiftUI/AppKit/PDFKit/PDFium. Это порядок развития, а не обещание сроков. Зависимости, требования к совместимости и доступность внешних сервисов могут изменить последовательность.

## Что обнаружено

- Нереализованные команды ленты после открытия PDF показывают «Функция в разработке». Кнопка сама по себе не считается готовой функцией.
- **Панели «Слои» и «Вложения» пока пустые**: сообщений об отсутствии данных недостаточно для утверждения, что этих данных действительно нет в документе.
- Часть возможностей работает в сокращённом виде; ниже они помечены как **частично**.

Основные источники: каталог `RibbonView.groups`, диспетчер `DocumentManager.perform`, обработчик `PDFViewer.Coordinator.performFeature`, содержимое `PanelBody`, движок `PDFiumSourceEditor.swift` и редактор `PDFTextEditingUI.swift`. Наличие кнопки или отдельного API в движке не считается готовой пользовательской функцией.

## 2. Небольшие подсистемы интерфейса

| № | Задача / текущий статус | Критерий готовности |
|---:|---|---|
| 1 | **Настройка ленты** — отсутствует (`customize`) | Скрывать/переставлять команды и группы, сохранять профиль, сбрасывать его без изменения состава функций приложения. |
| 2 | **Проверка орфографии** — отсутствует (`spell`) | Явно запущенная проверка существующего текста RU/EN с переходом к месту ошибки. Исправление выполняется через исходный текстовый редактор, без автоматической OCR. |
| 3 | **Вложения PDF** — панель-заглушка | Перечисление EmbeddedFiles, открытие, извлечение, добавление и удаление с сохранением. Пустой список только после реального чтения дерева вложений. |
| 4 | **Изменение размера страницы** — отсутствует (`resize`) | Изменять MediaBox/CropBox, отдельно предлагать масштабирование содержимого; корректировать аннотации и переходы. |
| 5 | **Именованные назначения** — отсутствуют (`bookmarkDestination`, `bookmarkNamed`) | Читать/создавать дерево именованных назначений, преобразовывать его в прямые переходы и обратно без потери ссылок. |
| 6 | **Автозакладки из заголовков / сложного содержания** — частично (`bookmarkFromPageText`, `bookmarkFromTOC`) | Определять уровни заголовков по шрифтам/геометрии, поддерживать многостраничное содержание, смещение печатных номеров и предварительный просмотр. Сейчас используется первая строка страницы либо строки содержания текущей страницы по простому шаблону. |
| 7 | **Обмен деревом закладок и расширенная проверка** — частично (`bookmarkFromFile`, `bookmarkHTML`, `bookmarkText`, `bookmarkValidate`, `bookmarkLinks`) | Импорт/экспорт иерархии без потерь, предпросмотр массовых изменений, проверка всех типов действий, ссылки по выбранному диапазону. Сейчас текстовый импорт создаёт плоские узлы; HTML плоский; TXT отражает отступы, но импорт не восстанавливает уровни; проверка ищет недействительные цели страниц. |
| 8 | **Расширенный редактор форм** — частично (`selectFields`, поля, `import`, `export`) | Группы радиокнопок, обязательные/только для чтения поля, настройки вариантов, порядок Tab, ограничения ввода и FDF/XFDF. Сейчас доступны основные виджеты, нативное заполнение, сброс и JSON. Выполнение PDF JavaScript исключено из плана. |
| 9 | **Расширенные аннотации** — частично | Групповое выделение и поворот, вершины линий/выносок, частичный ластик штрихов, видимость/блокировка аннотаций, FDF/XFDF. Сейчас есть стандартные фигуры, перемещение/изменение размера/удаление; ластик удаляет аннотацию целиком, обмен комментариями идёт через PDF. |

## Дополнительные расширения оформления

- Произвольный угол водяного знака; обновление старого оформления без меток BotPlus требует отдельного распознавания.
- Фоновое изображение: режимы fit/tile и сохранение пропорций, помимо растягивания до CropBox.

## Производительность и регрессионные проверки

- Уменьшить стоимость полного снимка изменённого большого CAD PDF; строить каталоги видимых страниц постепенно.
- Ускорить первое чтение системных и встроенных шрифтов; кешировать каталог с корректной инвалидацией.
- Продолжить аппаратные проверки щипка на разных трекпадах и версиях macOS. Нативные проверки маршрутизации, якоря и накопления дельт не синтезируют физический жест.
- Проверять сохранение/повторное открытие, Undo/Redo, поворот и page boxes для каждой новой функции, включая Intel и Apple Silicon.

## Зависимости от владельца или внешнего окружения

- Developer ID и нотарификация Apple: нужны аккаунт, сертификат и профиль владельца. Текущая подпись ad-hoc; системный linkd может отклонять её без Team ID.
- Office-конвертеры: выбор движка восстановления структуры и политики совместимости.
- Системные службы и отсутствующие модели macOS описаны в [RUNTIME_ERRORS.md](RUNTIME_ERRORS.md); их восстановление не считается реализуемой командой PDF-редактора.
