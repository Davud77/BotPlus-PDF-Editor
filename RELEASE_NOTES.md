# BotPlus PDF Editor 1.3

- Новая кнопка «Главная → Объекты → Редактор содержимого»: исходные изображения, линии/контуры, заливки, текстовые объекты и целые PDF-группы.
- Перемещение и размер мышью, поворот ручкой или в свойствах, цвета/толщина/прозрачность, замена изображений, удаление, копирование/вставка PDF-объектов и Undo.
- Точный выбор диагональных линий и заполненных контуров. Общие XObjects меняются целиком, без перезаписи дочерних ресурсов других экземпляров. Градиенты/узоры и редактирование узлов кривых пока ограничены; геометрические изменения сохраняют исходное оформление.
- Исправлен диапазон основного зума: 5–2000% и логарифмический ползунок. Маршрутизация по окну под указателем учитывает плавающие окна и модальные диалоги, а не окно с клавиатурным фокусом.
- Команды документа неактивны без PDF; навигация, удаление страниц, буфер обмена и Undo учитывают состояние документа.
- В режимах руки/редактора объектов исключён лишний текстовый hit-testing PDFKit. Нативное выделение и поиск PDFKit всё ещё могут вызывать системный Live Text.
- В README добавлен настоящий скриншот стартового экрана с пустой историей.

Нативные проверки охватывают свойства/геометрию/удаление/буфер обмена, пиксельную прозрачность заменённого изображения, сохранение, клики и drag, Undo, доступность команд и полный диапазон масштаба. Universal macOS 14+: Apple Silicon и Intel. Подпись ad-hoc, без нотарификации Apple.

Системные XPC/linkd, TextRecognition/E5, отказ порта процесса, отмена ViewBridge, TCP reset и отсутствие DetachedSignatures разобраны в RUNTIME_ERRORS.md. Системные службы и защищённые базы не изменяются; журналы не подавляются.
