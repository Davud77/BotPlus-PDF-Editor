# BotPlus PDF Editor 1.4.1

## Зум и производительность

- Жесты PDF привязаны к документу: накопленное увеличение не переносится на другую вкладку.
- Устранены повторные публикации неизменного состояния выделения при прокрутке/масштабировании.
- Рамки объектов переиспользуются при зуме без повторной сборки каталога.
- Миниатюры новых пустых PDF показывают аннотации до первого сохранения.
- При первом жесте миниатюры используют лёгкий растр, затем повышают детализацию. Исправлен жизненный цикл таймера жеста при переключении/закрытии панели.

## Проверки

- Пакеты из 100 событий масштабирования, обратный жест, NaN, смена документа.
- Сохранение точки под курсором и масштабирование без смены фокуса/предварительного клика.
- Кеш миниатюр, upgrade детализации, повторное использование рамок объектов.
- Регрессии редактирования PDF, сохранения, аннотаций, оформления, фона и PNG/JPEG/TIFF.

## Возможности 1.4

Сохраняются поля с предпросмотром, колонтитулы, водяные знаки, Бейтс, цветной/графический фон, экспорт изображений с DPI/диапазоном/прозрачностью/прогрессом/отменой. Новый логотип и открытие PDF из Finder включены.

macOS 14+, Apple Silicon и Intel. Подпись ad-hoc, без нотарификации. Системная служба `linkd` может отклонять приложение без Team ID с ошибкой 4097; сертификата Apple Developer у владельца пока нет. Физический щипок не синтезируется проверочным API; тесты выполняют нативный обработчик жестов.
