# BotPlus PDF Editor 1.2

## Новое

- AGPL-3.0-only: полный LICENSE в репозитории и приложении, «Помощь → Лицензия».
- Стартовая страница: «Создать пустой» и десять последних PDF с именем, путём, размером и датой открытия. История сохраняется между запусками; повторный доступ использует sandbox-закладки.
- Проверка обновлений через GitHub Releases, сравнение версий и заметки релиза; установка вручную.
- Отправка текущей страницы/всего PDF через системное создание письма или меню доступа. Отправку подтверждает пользователь.
- Выравнивание выбранных полей текущей страницы по краям/центрам в координатах PDF.
- Замена диапазонов страниц с Undo и восстановлением прямых GoTo-переходов. Старые аннотации заменяются; ссылки за пределы импортированного диапазона удаляются.
- Независимые четыре отступа страницы в пунктах, диапазоны и Undo. Интерактивный предпросмотр остаётся в дорожной карте.

## Производительность и проверки

- Асинхронное чтение файла, повторное использование неизменённых PDF-байтов, общий кэш для редактирования и Undo.
- Выбор инструмента и режима просмотра не сбрасывает кэши содержимого. Значения форм, геометрия, аннотации, атрибуты и закладки проверяются перед использованием снимка.
- Геометрия строк рассчитывается один раз. Каталог страницы переиспользуется редактором с передачей исключительного владения PDFium-объектами.
- Добавлены воспроизводимые измерения реального PDF и проверки повторных изменений форм/аннотаций/закладок. Оригиналы пользовательских PDF не изменяются и не включаются в репозиторий.

## Ограничения

Открытые PDF с неизменной структурой страниц/закладок/атрибутов сохраняются с исходными потоками через временный файл. Полная пересборка после структурных изменений всё ещё может занимать несколько секунд. Кэшированные представления PDFKit, теряющие живые изменения, не используются. Службы macOS linkd/XPC и отсутствующие E5-модели находятся вне контроля приложения; системные журналы не подавляются. Нет обещания, что нативное выделение/поиск PDFKit никогда не запустит Live Text.

Universal macOS 14+: Apple Silicon и Intel. Подпись ad-hoc, без нотарификации Apple. Уведомления PDFium и его компонентов включены отдельно.
