# BotPlus PDF Editor 1.1.2

Исправление значков интерфейса для macOS 14+, Apple Silicon и Intel.

- Исправлен значок «Добавить закладку»: отсутствующий `bookmark.badge.plus` заменён на составной векторный значок «закладка +».
- Добавлена проверка доступности системных значков с кэшем. На старых поддерживаемых версиях macOS недоступный значок получает совместимый заменитель до рендеринга SwiftUI.
- Добавлена нативная регрессия значков всех 13 вкладок ленты и запасного значка.
- Дополнен разбор повторного журнала: системные ошибки E5, linkd, ViewBridge и сообщение неподдерживаемой локали.

Обновление сохраняет исправления линеек и жизненного цикла окон из 1.1.1. В новом журнале они не повторялись. Служба `linkd` и модели TextRecognition являются частью macOS; приложение не может восстановить их и не скрывает диагностические сообщения. Нативное выделение/поиск PDFKit по-прежнему может запускать системный Live Text.

## Установка

Откройте `BotPlus-PDF-Editor.dmg` и перетащите приложение в Applications. Сборка универсальная arm64/x86_64, с подписью ad-hoc, без нотарификации Apple. Контрольная сумма приложена.

Подробности: [разбор ошибок](https://github.com/Davud77/BotPlus-PDF-Editor/blob/main/RUNTIME_ERRORS.md).
