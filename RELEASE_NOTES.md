# BotPlus PDF Editor 1.7

- Автоматическая проверка стабильных GitHub Releases: после запуска и каждые 6 часов. Один релиз не открывает уведомление повторно за сеанс.
- Отдельное включение фоновой загрузки и установки при выходе. Однократный выбор папки текущей программы через sandbox-диалог, сохранение доступа, размер/SHA-256, проверка ZIP, подписи, bundle ID, версии и Intel/Apple Silicon; копия предыдущей сборки и откат.
- «Пропустить версию», «Не уведомлять месяц», сброс ограничений; ручная проверка остаётся доступной.
- Перед установкой сохраняются копии открытых PDF из всех окон. При следующем запуске восстановленные документы открываются как несохранённые копии; оригиналы не перезаписываются. Приложение автоматически не перезапускается.
- Вид → Зазор страниц: настройка 0–40 pt с сохранением для новых окон, без пересборки PDF и сброса зума. Выполненный пункт 31 удалён из дорожной карты.
- Снимок области: прозрачный фон, небольшой предпросмотр в свойствах и сохранение PNG. Предпросмотр готовится в фоне с ограничением 500 px; полное изображение сохраняет выбранный DPI.
- Прогресс загрузки ограничен по частоте; завершённая/отменённая передача не может обновить прогресс новой. Диалоги и публикации состояния остаются на MainActor.
- Universal DMG плюс отдельный архив автоустановки. Нативные проверки зума без фокуса, ZIP-путей/симлинков/контрольных сумм, отката, подписанного архива, зазора и прозрачного снимка.

**Первая установка:** 1.7 нужно установить вручную из DMG. Автоустановщик есть в 1.7 для следующих релизов; предыдущие версии содержали только проверку. Текущая подпись ad-hoc, без Developer ID/нотарификации; ограничения `linkd` не маскируются. Подробнее: [UPDATES.md](UPDATES.md).

# BotPlus PDF Editor 1.6

- Извлечение выбранного диапазона страниц в отдельный PDF; сохранение иерархии закладок, прямых внутренних переходов и метаданных аннотаций. Переходы на неэкспортированные страницы удаляются. Исходный файл защищён от случайной перезаписи.
- Разделение по количеству страниц или целям закладок первого уровня. Диапазон, прогресс, отмена и новая папка результатов; существующие файлы не заменяются.
- Произвольный порядок страниц, включая обратные диапазоны, с проверкой полного набора без повторов, сохранением прямых переходов и Undo.
- Снимок области: Вид → Снимок области. Выбор 72–600 DPI в свойствах, PNG в буфер обмена, корректные повороты/CropBox, ограничение 40 Мп. Более позднее копирование не перезаписывается результатом медленного снимка.
- Настоящая история просмотра отдельно для каждого документа: страница, масштаб, центр и режим отображения. Верхние стрелки и «Предыдущий/следующий вид» используют историю; навигация страниц в статусной строке сохранена. История ограничена 150 видами и не сериализует PDF.
- Исправлено увеличение растров при высоком DPI в снимках, экспорте и миниатюрах.
- Поиск запускается по Enter, не при каждом символе. Убрана лишняя очередь задач из уведомлений viewport; масштаб области/снимок не увеличивают ревизию содержимого. Прогресс экспорта ограничен 30 обновлениями/с.
- «Снимок» добавлен также на «Главную». Межстраничные поля уменьшены; центрирование короткой страницы добавляет отступы у документа, а не между каждым листом.
- Дорожная карта обновлена по новым примерам: удалены SharePoint, DocuSign, криптографические подписи, PDF JavaScript, аудио/видео, 3D и RMS. Добавлены вкладки/несколько видов, групповые миниатюры, расширенная печать, развитие снимка и настройка зазора. Номера задач теперь сохраняются.

## Ограничения

Экспорт создаёт отдельные PDF без переноса шифрования исходника; копирование должно быть разрешено документом. Перенос дерева именованных назначений и специальных действий остаётся в дорожной карте. История очищается после изменения количества/порядка страниц и Undo/Redo; она хранится в текущем сеансе.

macOS 14+, Intel и Apple Silicon. Приложение подписано ad-hoc, без нотарификации. Аппаратный щипок не синтезируется нативными проверками.
