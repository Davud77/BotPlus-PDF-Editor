# Обновления BotPlus PDF Editor

Начиная с **1.7**, настройки доступны в **Помощь → Проверить обновления** и **BotPlus PDF Editor → Обновления**.

## Настройки

- Автоматическая проверка включена по умолчанию: через 30 секунд после запуска, затем каждые 6 часов, пока приложение работает. Проверяется только последний стабильный релиз `Davud77/BotPlus-PDF-Editor`. За сеанс один релиз не открывает уведомление многократно.
- **Загружать и устанавливать при выходе** выключено по умолчанию. Включение разрешает фоновую загрузку и установку при обычном завершении приложения; обновление не заставляет закрывать PDF во время работы.
- **Пропустить версию** относится только к этому номеру; следующая версия снова предлагается.
- **Не уведомлять месяц** задаёт календарный месяц, включая переходы между месяцами разной длины. Скрывает автоматическое предложение и автоустановку до указанной даты.
- **Вернуть уведомления** сбрасывает оба ограничения. Ручная проверка показывает релиз независимо от них; его можно скачать вручную.

## Первая установка обновления

1. Версию 1.7 необходимо один раз установить из DMG: старые версии не содержат установщика.
2. Приложение должно находиться в обычной доступной для записи папке, например `~/Applications`, а не работать прямо с DMG или из App Translocation.
3. После загрузки нажмите **Установить при выходе…** и выберите папку, в которой находится текущая `.app`. Это предоставляет приложению доступ App Sandbox. Доступ сохраняется закладкой; если macOS отклонит или аннулирует её, папку потребуется выбрать повторно.
4. Завершите приложение. Перед заменой сохраняются отдельные копии всех открытых PDF и незавершённое исходное редактирование фиксируется. Выполняющаяся операция с PDF сначала должна завершиться или быть отменена.
5. Следующий запуск открывает новую версию. Документы восстанавливаются как **несохранённые копии** с исходными именами, страницей и масштабом. **Сохранить как** позволяет сохранить изменения, не перезаписав оригинал молча.

Обновление не запускает приложение автоматически после выхода. Обновление при выходе выбрано для сохранения рабочего процесса; перезапуск остаётся обычным запуском из Finder/Dock.

Если папка принадлежит администратору и недоступна для записи, обновление остаётся загруженным, приложение не завершается, а установленная версия сохраняется. Привилегированного установщика, `sudo` и фоновой системной службы нет. Можно установить DMG вручную или перенести приложение в доступную пользователю папку.

## Проверки и откат

- Загрузка только по HTTPS с фиксированного GitHub-репозитория; редиректы разрешены только на конкретные домены доставки GitHub.
- Размер архива ограничен 128 МБ; проверяются размер и SHA-256 из GitHub Release asset digest либо соответствующего `.sha256`.
- До распаковки проверяется центральный каталог ZIP: запрещены абсолютные/внешние пути, `..`, симлинки, шифрование, ZIP64 и выход более 512 МБ. Архив содержит только `BotPlus PDF Editor.app`, без ссылки `/Applications`.
- До установки проверяются целостность подписи всех архитектур/вложенного кода, bundle ID `com.botplus.pdfeditor`, номер версии, наличие Intel/Apple Silicon и исполняемого файла. Обновление должно быть новее установленной версии. Если текущая сборка имеет Team ID, новая должна сохранять его.
- Новая копия сначала помещается на тот же том. Предыдущая `.app` переименовывается в `BotPlus PDF Editor.previous-<UUID>.app`; при неуспешном перемещении новой копии выполняется откат. Эта предыдущая сборка остаётся в папке установки и может быть удалена пользователем после проверки новой версии.
- Копии документов находятся в контейнере приложения, `Application Support/BotPlusUpdateRecovery/<UUID>`, с правами папки 0700 и файлов 0600. Они не отправляются на сервер и не удаляются при восстановлении. Это обычные PDF-копии, не дополнительное шифрованное хранилище; их можно удалить после сохранения документов.

**Ограничение доверия:** текущие релизы подписаны ad-hoc, без Developer ID и нотарификации. SHA-256 подтверждает соответствие файлу, опубликованному GitHub, но не является независимой подписью издателя: доверие зависит от HTTPS и безопасности аккаунта/репозитория GitHub. Автоустановка требует отдельного включения. Gatekeeper, quarantine и sandbox не отключаются. Ошибки `linkd.autoShortcut` без Team ID остаются системным ограничением; автообновление не заменяет сертификат Apple.

## Выпуск релиза

`./build_and_deploy.sh --package-only` создаёт:

- `dist/BotPlus-PDF-Editor.dmg` и `.dmg.sha256` — обычная установка;
- `dist/BotPlus-PDF-Editor-update.zip` и `.zip.sha256` — установка из приложения.

Все четыре файла необходимо прикреплять к одному стабильному GitHub Release с тегом `vX.Y` или `vX.Y.Z`; номер должен совпадать с `CFBundleShortVersionString`. В ZIP сохраняются подписи `.app` и PDFium. После публикации релиз автоматически обнаруживается предыдущей версией **1.7 или новее**. Сборка 1.7 проверяет обе архитектуры через заголовок Mach-O, без зависимости от особенностей командной строки `lipo`.

Проверки:

```sh
./Tools/verify_native.sh
./build_and_deploy.sh --package-only
./Tools/verify_update_archive.sh
```

Проверка установки работает на временной копии `.app`, проверяет подпись, смену 1.6 → 1.7, резервную копию и отклонение повреждённого кода. Она не заменяет аппаратную проверку выдачи sandbox-доступа через NSOpenPanel и обновления установленного приложения на конкретной macOS. При изменении версии обновите ожидаемые номера в `Tests/UpdateInstallChecks.swift` вместе с номером релиза.

Публичные API и требования Apple: [доступ к файлам App Sandbox](https://developer.apple.com/documentation/security/accessing-files-from-the-macos-app-sandbox), [защита данных App Sandbox](https://developer.apple.com/documentation/security/protecting-user-data-with-app-sandbox). Для записи исполняемых файлов в выбранной папке используется entitlement `com.apple.security.files.user-selected.executable`; песочница приложения остаётся включённой.
